# Android Application Coursework

![Android](https://img.shields.io/badge/Android-Coursework-3DDC84?logo=android&logoColor=white) ![Java](https://img.shields.io/badge/Java-Android%20SDK-ED8B00?logo=openjdk&logoColor=white)

A collection of separate Android Studio exercises exploring Java, Android UI components, navigation, local data, and simple app interactions.

| Folder | Exercise |
| --- | --- |
| [TicTacToe](TicTacToe/) | Basic tic-tac-toe app |
| [TicTacToe2](TicTacToe2/) | Tic-tac-toe with a board and presenter structure |
| [Week1](Week1/) | Introductory Android activity and layout |
| [Week2](Week2/) | List adapters and custom row presentation |
| [Week3](Week3/) | Post list with text and image content |
| [Week4](Week4/) | WebView with an address input |
| [Week6](Week6/) | Movie list using fragments and RecyclerView |
| [week8](week8/) | Image download and preview exercise |
| [week10](week10/) | Local notes app using fragments and file storage |

## Open a project

Each folder is an independent Android Studio project with its own Gradle wrapper. Open the chosen folder in Android Studio, allow Gradle to sync, and run it on an emulator or Android device.

> Coursework archive. Individual projects demonstrate specific concepts rather than a single integrated app.
